# Privacy Policy - TBC Wedding Board Reader

_Last updated: 15 November 2026_

TBC Wedding Board Reader is a personal, single-user tool that reads the owner's own Pinterest boards and pins so they can be used as inspiration for wedding planning.

**Data accessed.** With the owner's Pinterest access token, the app reads the owner's own boards and pins (titles, descriptions, image links, source links). It requests read-only permissions and never creates, edits or deletes content.

**Data storage and sharing.** The app runs only on the owner's own computer. It does not operate any server, does not collect data from other people, and does not sell, share or transmit Pinterest data to third parties. Retrieved data is used locally in the owner's own AI assistant session and in files the owner saves.

**Access token.** The token is stored only on the owner's computer and can be revoked at any time in the Pinterest developer settings.

**Other users.** The app is not offered to the public and does not process data of any other Pinterest users.

**Contact.** Questions can be raised through the owner's Pinterest profile.
